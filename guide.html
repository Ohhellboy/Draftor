安装操作说明

适用于微雪 ESP32-S3-RLCD-4.2（ST7305）。请亲自核对板型。USB 名称和芯片型号只能辅助识别。根据你是否要保留原机数据，选择下面一种。

第一次安装、其他固件 → 清空安装 已在用 Alpha 3 → 重新安装

开始前 · 安装后开机 · 准备 TF 卡 · 遇到问题

先准备好设备

  1. 用 Windows 10/11 电脑打开桌面 Chrome 或 Edge，或在 Mac 上用桌面 Chrome。准备一根能传数据的 USB 线。
  2. 保存打开的文稿，结束文件传输。拔下 USB，关掉电池供电。完全断电后取出 TF 卡，留到安装完成后再插。已经能写作的原卡可继续用。
  3. 断开其他开发板，关闭串口监视器及其他安装页。Windows 现场已成功的顺序为 连接 USB → 长按 PWR 关机 → 按住 BOOT → 短按 PWR 开机 → 等约 2 秒后松开 BOOT。保持 USB 接好。

稍后浏览器会弹出串口选择框。选这块板对应的 USB JTAG/serial debug unit，再点连接。Windows 上也可能叫 USB 串行设备 (COM…) 或 USB Serial Device (COM…)。忽略蓝牙和调试控制台。

第一次安装，或备份后清空安装

不同厂家版本、其他固件、未知分区和空白板都可以选择这个入口。网页核对实际硬件、安全状态和目标固件后，再提供安装。清空安装会覆盖设备内部的全部内容。

  1. 从首页点第一次安装／清空安装。在打开的页面点连接设备并安装。
  2. 核对板型、文稿已保存和 TF 已取出，勾选对应准备项。点选择串口并只读检查，选择这块板并连接。等待检查。看到“旧固件未识别”时可继续备份。
  3. 点读取完整 Flash（只读）。读完后点保存私人恢复 ZIP，把 Draftor-private-device-original-….zip 保存到自己的电脑。等下载完成，在回选已保存的私人恢复 ZIP选择这个 ZIP，保持压缩格式。
  4. 等页面显示保存文件回选通过，与当前同一设备完整 Flash 一致。 点下载离线恢复工具（HTML），把 Draftor_Recovery_R13_Offline.html 和 ZIP 放在一起，确认保存完成。它们可把本次原机完整内容写回这块板，请私下保留。
  5. 阅读覆盖影响，勾选我已阅读上述影响，确认清空这块设备的全部内部 Flash 并安装 Draftor。 点按已核验计划安装一次。等待擦除、安装与核验，保持 USB、供电和页面。
  6. 等到内容已校验，普通启动待确认。 再按下方步骤普通开机。

如果完整 Flash 已核对为全空白，页面会明确说明并跳过 ZIP 和离线工具保存。直接阅读并确认一次清空安装。

已经是受支持的 Alpha 3 时，本页可能提供保留数据的同版本重装。可以回到首页使用小型保护文件流程。若保留数据重装无法确认兼容，页面会给出清空安装入口。

打开清空安装

已经在用 Alpha 3，重新安装

  1. 从首页点重新安装 Alpha 3，再点以上准备已完成，连接设备。在浏览器的窗口选这块板，点连接。
  2. 等页面核对设备和需要保留的数据。看到重新安装当前版本并且按钮可用后，点保存保护文件并重新安装。
  3. 在保存窗口把 Draftor-install-protection-….json 存到自己的电脑，保留默认文件名。点保存后网页会自动读回，核对成功就开始重装。这个小文件记录原板的身份、原状态和少量保护数据。它依赖板上保留的私人区域，不能代替完整系统备份。私下留存，出现中断时需要它。
  4. 如果页面改为显示下载安装保护文件，点它并保存 JSON。在回选已保存的保护文件选择同一文件。核验通过后点按上述范围安装。
  5. 看到正在安装，请保持供电和连接。或正在核验写入内容与保留区域…时，请等待。保持 USB 插着，别关页或关机。等到安装内容已校验，等待普通启动。再普通开机。

返回首页重新安装 · 另存完整备份

安装后，开机写作

  1. 看到对应的完成提示，连接即已关闭。拔下 USB，关掉电池供电。完全断电后插回准备好的 TF 卡。
  2. 松开 BOOT，像平时一样开机。清空安装后按屏幕提示配对键盘。保留数据重装后切回原键盘通道，直接唤醒。
  3. 看到写作界面后试一下输入。有旧稿就打开检查。用新名字保存一份短稿，正常关机再开机，确认还能读到。

第一次准备 TF 卡

原卡如果已能在 Alpha 3 正常写作，可直接沿用。新卡请在电脑上用读卡器准备，安装结束、机器彻底断电后再插入。网页不会替你向卡上复制文件。

  1. 展开首页下载 TF 卡资源，点下载基础资源包和下载学习索引包。在电脑上分别解压两个 ZIP。
  2. Draftor_v0.1.0-alpha.2.1_Resources.zip：打开解压后的 Resources，把里面 HANIME 的资源合并到卡最外层的 HANIME/。
  3. Draftor_v0.1.0-alpha.3_WAVESHARE_RLCD42_LearningIndex.zip：打开它的 Resources，把 WAVESHARE_R7_L1_AREV1_RES_20261112 文件夹复制到卡最外层。里面应同时有 relations.bgr 和 relations.hnv。

打开卡时应直接看到上面两个文件夹。保留原卡上的文稿和个人学习资料，无需格式化。遇到同名冲突，请先保留原文件，再对照清单核对，避免覆盖整个文件夹。查看 TF 目录和文件清单

遇到问题

串口窗口里找不到设备
先取消选口。换一根能传数据的线，关闭占用串口的程序，然后重复上面的 BOOT＋PWR 顺序。在 Windows 的“设备管理器 → 端口（COM 和 LPT）”查看这块板插入后出现的项目。Windows 连接帮助
在系统保存窗口点了取消
重装页会提示“已取消保存，未开始写入，连接已关闭”。关掉弹窗，从首页再点“重新安装 Alpha 3”，重新选择设备并保存。清空安装页若取消了 ZIP 或 HTML 下载，先重新保存对应文件，完成回选或保存确认后再安装。
连接中断
如果页面显示“尚未擦除或写入，原机 Flash 内容未被本次操作修改”，可关闭弹窗、检查连接后重新开始。只有已开始擦写后中断，才需要用下一条的恢复方式处理。
安装失败、写入中断或校验未通过
先看页面是否说明已经开始擦写。若尚未擦写，按错误提示纠正文件或连接后重新开始。若擦写已中断，保留设备现状，点“保存脱敏回执”，关闭连接。用本次完整 ZIP 和 R13 离线 HTML 恢复，具体步骤见备份与原系统恢复说明，按说明使用两份文件恢复。恢复会覆盖内部内容并回到备份时的原固件，即使当前固件或分区已损坏也能先核验原板。只有小型保护 JSON 时，请私下留存，并向项目反馈提供错误文字和脱敏回执。公开恢复工具需要完整 ZIP。请勿上传私人 JSON、ZIP 或文稿，也不要直接再点安装。

Installation guide

Use desktop Chrome or Edge on Windows 10/11, or Chrome on macOS. Use a USB data cable and the Waveshare ESP32-S3-RLCD-4.2 (ST7305). Windows hardware testing is pending.

  1. Save your writing and end transfers. Disconnect USB and battery power. Remove the TF card. Disconnect other boards and close serial monitors. With USB connected, hold PWR to power off, hold BOOT, briefly press PWR to power on, then release BOOT after about two seconds.
  2. First installation or other firmware? Open First-time / clean installation. Confirm the board and preparation, then select its USB port. Unrecognized firmware can proceed after backup. Read the full Flash, save the original-device ZIP and reselect the saved file. Save Draftor_Recovery_R13_Offline.html beside it. Confirm once that all internal Flash will be erased, then start the verified plan. A verified entirely blank board skips backup. Keep personal files private.
  3. Already on Alpha 3? Choose Reinstall Alpha 3, then Preparation complete — connect. Select the board and connect. Once the current version is recognized, click Save protection and reinstall. Save the suggested protection JSON locally. The site reads it back, then starts the reinstall. If offered the download alternative, download the JSON, reselect that exact file, then start installation. Keep it private. Full backup and recovery use a separate ZIP.
  4. Leave USB, power and the page connected until verification finishes. Power off fully, insert the prepared TF card, release BOOT and start normally. Pair the keyboard on first install or use its original channel after reinstall. Open the writing screen and check that a new document survives a restart.
  5. For a new TF card, download both ZIPs from the home page and unzip them. Copy Resources/HANIME/ from the base ZIP and Resources/WAVESHARE_R7_L1_AREV1_RES_20261112/ from the LearningIndex ZIP directly to the card root, without the Resources wrapper. Preserve personal files. TF file list

If the board is absent, check the cable, BOOT and PWR sequence and Windows Device Manager. Cancelling the native protection save closes the connection before writing, so you can restart from the home page. After a write failure or uncertain interruption, stop and keep the sanitized receipt. Use your own full ZIP and offline tool through Backup & recovery, or contact project support with the error and sanitized receipt. Keep private files on your computer.
