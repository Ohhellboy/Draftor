安装中断处理 / Interrupted installation

未开始写入：可以从首页重新连接检查。已开始写入或结果不明：不要重复点击安装，也不要普通启动。保留安装保护文件，保持 TF 在外，手动回 ROM 后使用这里。请确认原微雪 ST7305、仅该板连接、文稿已保存且传输已结束、TF 已在完全断电后取出、ROM 模式及串口监视器已关闭。

Before writing: reconnect from Home for new checks. Once writing began or the outcome is uncertain: do not retry installation or boot normally. Keep the protection file and TF outside, return to ROM manually and use this page. Confirm the original Waveshare ST7305 only, saved documents, ended transfers, TF removed after full power off, ROM mode and closed serial monitors.

这里先只读重建原系统文件。原板身份、私人区域或恢复摘要不匹配就停止。没有保护文件或私人区域已损坏时，此路径不能恢复；保留现场，使用独立完整备份。恢复厂家原系统会回到厂家演示。不会降级到其他历史版本。

Read-only reconstruction first. A different board, changed private regions or a digest mismatch stops the process. Without the protection file or intact private regions this path cannot recover; preserve the device and use a separate full backup. Factory recovery returns the factory demo. No cross-version downgrade.

尚未连接 / Not connected

保存重建 ZIP 不等于恢复完成。后续完整恢复覆盖全部 16 MiB，需再次确认；不操作 TF。R12 重建包必须用对应 R12 工具，旧 R11 工具会拒绝这种证明格式。

Saving the ZIP is not restoration. Full 16 MiB restore needs separate confirmation and never accesses TF. Reconstructed R12 packages need the matching R12 tool; R11 rejects this proof format.
