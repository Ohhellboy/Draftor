The matching TF card uses the [learning index](https://github.com/Ohhellboy/Draftor/releases/download/v0.1.0-alpha.3/Draftor_v0.1.0-alpha.3_WAVESHARE_RLCD42_LearningIndex.zip) and the [shared dictionary and font](https://github.com/Ohhellboy/Draftor/releases/download/v0.1.0-alpha.2.1/Draftor_v0.1.0-alpha.2.1_Resources.zip). Verify sizes and SHA-256 against `Firmware/TF_RESOURCES.json`.
