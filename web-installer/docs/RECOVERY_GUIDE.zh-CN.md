# Draftor 备份与恢复

仅适用于微雪 ESP32-S3-RLCD-4.2 / ST7305、16 MiB，以及准确 Alpha 3 app0 或 FactoryOnly 20260120 原始状态。本轮候选尚未获准公开写入。锁写诊断版不能恢复。

## 先保存自己的恢复包

1. 保存文稿、结束传输。彻底断电（包括电池）后取出 TF，只连接这一块微雪。按住 BOOT 接 USB，约两秒后松开。关闭串口监视器。
2. 打开“备份与恢复”，选择“保存私人恢复包”，确认实物和 TF 条件，然后选 USB JTAG/serial debug unit。只读检查不会擦写。
3. 如已有完整 16 MiB `.bin`，展开已有备份选项并选择它。工具只有在其内容与当前设备完整 ROM 摘要一致时才生成真实恢复凭据。App 切片不能替代整片备份。旧文件不匹配时保留旧文件，再使用“读取当前完整 Flash”。
4. 下载新命名的私人恢复 ZIP，等待浏览器完成保存。选择“回选已保存的恢复包”，从实际保存目录重新选该 ZIP。只有显示回选通过才算备份准备完成。
5. 保存离线工具，将其与私人包留在本机；不要只依靠一个已打开的网页。锁写版下载的是锁写离线诊断工具，真实恢复候选另行交付审核。
6. 关闭连接，再保存脱敏诊断回执。

私人 ZIP 包含 `manifest.json`、固定 16,777,216 字节的 `flash.bin` 及两份说明。它含设备 MAC、设置、配对和可能的内部文稿，不能公开上传或放进源码/网站。TF 文件不在其中，须独立保留；工具不读取或修改 TF。不需要云端账号。

## 故障后恢复

1. 使用之前保存的离线工具，重新打开一次新会话，选择“恢复原设备”。选择私人 ZIP，不要解压、手工修改清单或填写地址。
2. 按上方断电、取出 TF、BOOT 的步骤，将原板进入 ROM，选择原设备串口。当前固件可无法启动，分区/OTA 也可损坏；工具仍必须实际读到正确原身份、芯片、容量及安全状态。
3. 阅读检查结果。若包来自厂家演示，恢复结果是厂家演示，不能当作 Draftor 安装成功。
4. 单独确认覆盖全部 16 MiB 内部 Flash。备份后的内部设置、配对及文稿变化将回退。TF 文稿不在包中，本工具不能找回损坏或删除的 TF 文件。
5. 点击一次恢复，保持 USB 和页面。工具用原 ROM 通道写回完整镜像，随后读取实际 ROM 全片 MD5 和元数据校验，不自动复位。
6. 显示内容核验通过仍不等于可正常写作。先关闭连接、保存回执。彻底断电，插回原 TF，普通启动；原键盘用原通道回连，检查旧稿、新稿保存及重启读取。厂家包则检查厂家演示。

本轮现场恢复必须等待对冻结工具和具体私人包的最终确认。最多一次恢复尝试，失败后不得自行再次擦写。

## 停止和纠错

未选文件、选错文件、取消串口选择可在界面纠正；没有打开串口不等于设备通信失败。真实协议、安全或写后核验异常必须停止，释放能释放的串口并保存回执。写命令已尝试而未收到确认时，内容可能已经部分改变；不能承诺取消后原样。没有自动重连、换槽、清空、重刷或后台恢复。

关闭失败时可能仍占用串口。先保存脱敏回执并关闭标签；不要让两个工具同时打开它。“再次只读核验”需要手动建立新连接，只核验实际内容，不重试写入。独立 Python 校验仅为本轮工程验收证据，不是普通用户操作依赖。

## 能力与隐私边界

恢复包采用受限 ZIP v1，只接受工具产生的四个 STORE 条目；不支持压缩、ZIP64、附加文件、重复路径、任意 JSON 或第三方恢复包。原固件须匹配有限的公开指纹。安全信息及设备身份来自创建时 ROM/eFuse 实读，恢复时再读取；不是由 Flash 文件证明。

MAC 和摘要只防误选与意外损坏，不是数字签名或防伪证明。诊断回执不含 MAC、私人摘要、文件名或内容；它记录程序控制点，不能冒充独立串口抓线。关闭会清除界面、引用、可控制的字节数组及 Blob URL；JavaScript 无法保证物理内存立即归零。

桌面 macOS Chrome 是本轮验证目标。Windows、Edge 和手机真实恢复尚未验收；手机仅提供说明与下载。网络断开重启工具的实测结果见 R9_REPORT，不能仅凭下载成功宣称离线通过。
