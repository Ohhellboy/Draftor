私有备份与恢复
Private backup and recovery

这是待审候选。普通用户的端到端恢复交互仍待独立验收，当前不对公众开放写入。
This is a review candidate. Ordinary-user end-to-end recovery still needs independent qualification. Public writing remains locked.

  1. 先保存所有文稿，正常结束传输，完整备份 TF 文稿和学习目录。完全断电（含电池）后取出 TF，只连接这一块微雪，按住 BOOT 插 USB 进入 ROM。
    Save writing, finish transfers and separately back up TF documents and learning directories. Fully remove power including battery before removing TF. Connect only this board; hold BOOT while connecting USB to enter ROM.
  2. 网页只读计划就绪后，选择只读备份完整 Flash；选择保存位置并等下载完成。文件为 16,777,216 字节，包含私有文稿、设置和蓝牙配对，不要上传或分享。
    After inspection, capture and save a full Flash backup. Wait for download completion. The 16,777,216-byte file may contain private writing, settings and pairing. Never upload or share it.
  3. 在网页重新选择刚保存的文件。网页会核对完整长度、当前设备 ROM MD5，以及刚读取备份的 SHA-256（如适用）。下载点击或勾选声明都不算备份证明。已有完整备份可直接选择，但必须与当前完整 Flash 一致。
    Reopen the saved file. The page checks size and the current full-device ROM MD5, plus the captured SHA-256 where applicable. Neither a download click nor a checkbox is proof. An existing full backup must match the entire current Flash.
  4. 保留完整备份的第二份副本和 SHA-256（macOS 可在终端用 shasum -a 256 文件名 记录）。这不会替代 TF 的独立备份。
    Retain a second copy and a SHA-256 record. This does not replace TF backups.

如果更新中断 / If installation is interrupted

立即停止，保存脱敏回执并保留私有备份。不要重试、换槽、尝试 fresh 或重置键盘配对。保持 TF 在外；恢复前需确认仍是备份对应的原板、备份长度/摘要正确、安全状态未变。恢复会改写整个内部 Flash；不能用 App 切片代替整片备份。
Stop, keep the sanitized receipt and private backup. Do not retry, change slots, fall back to fresh or reset pairing. Keep TF out. Recovery requires the same original board, the complete verified backup and unchanged security state. Full recovery overwrites internal Flash; an App slice is insufficient.

R6 已用准确 Python esptool 5.3.1、ROM/no-stub/no-reset、keep flash 参数及无压缩完整恢复验证了这一原始备份格式。公开候选目前不提供自动恢复按钮，也不把高级命令当作普通用户已经具备恢复能力的证明。应由有经验的操作人员按恢复前检、单独确认、完整写入、独立 verify-flash、普通启动及原键盘/旧稿检查的顺序执行。
R6 qualified this raw backup format with exact Python esptool 5.3.1, ROM/no-stub/no-reset, keep Flash parameters, uncompressed full restoration and independent verify-flash. This candidate does not offer automatic recovery or assume advanced commands prove user readiness. Recovery needs an experienced operator, checked identity/security/backup, separate approval, complete restoration, independent verification and normal boot with original keyboard/documents.

此缺口属于公开安装阻碍，不能靠勾选“已备份”绕过。首装会清除全部 16 MiB，包括旧设置和配对；兼容更新只改 App，但中断同样可能无法启动。
This recovery-usability gap blocks public installation and cannot be waived by a checkbox. First installation erases all 16 MiB including settings and pairing; an interrupted App-only update may also prevent boot.
