# R11 → R12 完整操作轨迹

计数口径：正常路径、无已存旧文件；每个按钮/复选框/文件行/打开/保存算一次鼠标点击。等待、滚轮、键盘输入另记，不偷算成零点击。原生文件窗口的额外目录导航或覆盖确认按实际增加。不含读说明、完成后关闭弹窗、下载回执、TF 实物和普通启动动作。

## R12 正常轨迹

| 顺序 | 操作 | 实际承担的责任 |
| --- | --- | --- |
| 1 | 首页“连接设备并安装” | 保持首页统一入口 |
| 2 | “以上准备已完成，连接设备” | 明确合并板型、保存文稿、断电取 TF、ROM、关闭其他串口的实物确认 |
| 3 | 浏览器串口窗口选设备行 | 由用户选物理连接，程序随后读取 ROM 身份 |
| 4 | 浏览器连接 | 芯片/容量/安全/指纹/分区/OTA 自动识别；自动读取最小保护数据 |
| 5 | 根据识别结果“保存保护文件并重装”或“保存保护文件，清空内部 Flash 并安装” | 明示安装影响；厂家保留明确清除同意 |
| 6 | 原生文件窗口保存 | 写到所选位置、重新读取并核验；自动最后复核、单次写入、校验、关闭 |

目标是两条路径均 6 次。软件页的串口窗口明确为模拟窗口；不能据此宣称 Windows 原生串口鼠标轨迹或真实 USB 通过。用户已在当前 macOS Chrome 用正常保存窗口完成两条软件路径。重装完成页 DOM 实际记录上述前 5 次可信点击；保存由用户完成，原生窗口内的额外目录导航/键盘/点击数未独立记录。厂家完成截图已保存，但用户随后将同一标签导航至重装页，厂家旧 DOM 点击记录没有保留。因此 6 次是完整标准轨迹；不冒充两条路径都有原生窗口逐点击录像。

## 人工步骤变化

| R11 人工操作 | R12 处理 | 保留的保护 |
| --- | --- | --- |
| 两个实物复选框 + 连接 | 一个明确列出条件的连接确认按钮 | 用户仍确认实物；不伪造已检查 TF |
| 选择何时读取整片、等待整片 | 自动慢读必要 28 KiB / 1,120 字节，读取摘要核对其他区域 | 厂家可变数据不丢弃；重装私人区不写 |
| 完整 ZIP 保存 + 文件回选 | 小型保护 JSON 一次保存，程序从正常文件句柄实际读回 | 不用点击下载冒充落盘，保存失败不写 |
| 选择厂家/重装哪个旧 ZIP | 无；保护文件按当前原板自动生成 | 会话独有文件摘要，错文件/错板拒绝 |
| 预下载离线 HTML + 已保存声明 | 从默认安装中移出，保留独立入口 | 全离线/独立副本需求依旧走完整备份与离线工具 |
| 完整备份声明 | 删除 | 新小型保护凭据是真实的，不能标记成完整备份通过 |
| 计划确认 + 厂家清除复选框 + 安装 | 明示影响的单次保存并安装按钮 | 厂家清除含义仍在按钮文本；底层要求 plan/erase consent |
| 可选旧 App 手动选择 | 正常公开路径不再展示 | 只允许精确已发布同版本 App，ROM 旧 App 摘要仍核对 |

没有让用户输入 MAC、选择 App 槽或理解分区；这些一直由机器核对。独立完整备份、原系统恢复、TF 下载均保留。不支持原生自动读回的浏览器走小文件下载/回选分支，会超过 6 次，须如实记账。
