本文档适用于 Draftor Alpha 3 中使用的 bgIME。版本依据是发布标签 v0.1.0-alpha.3，对应提交 f18939f8880e2278c231739d553fbf983c19e0f6。教程和接口中的源码引用固定到这个提交。

版本依据

Draftor 产品版本与模块版本分别维护。kCompositionLearningApiVersion 是源码中的组合学习接口标记，值为 2，也不是一个新的 bgIME 发行版本。

版本定义见 Core CMake、Extension CMake、组合学习声明和产品版本约定。

源码与资源获取

源码随 Ohhellboy/Draftor 维护。Host 示例使用快速开始中的固定标签；需要实际输入词库时，按资源页面获取匹配的文件。文档所在网站与草稿机安装入口共用域名，路径独立为 /bgime/。

验证范围

现有产品验证针对微雪 ESP32-S3 与 ST7305 4.2 英寸设备。三个 Host 示例有 macOS 运行记录；其他 POSIX 环境、Windows 原生环境及新硬件需另行验证，具体条件见快速开始。

Alpha 3 的产品验证范围见 ALPHA3_VALIDATION.md。早期的查询与取字改进、对照测试和设备移植过程保留在性能记录、版本说明及微雪版本历史中；学习接口以本页固定的 Alpha 3 源码为准。

名称与标识使用

Draftor（草稿机）与 bgIME（大鹅输入法）分别标识写作设备项目和中文输入引擎。

Apache License 2.0 授予的软件使用权不包含一般性的项目品牌使用授权。第三方可以准确说明技术来源并保留必要的技术标识；独立发行、商业集成及非官方构建应明确自身身份，不得造成官方来源或背书混淆。

完整规定见名称与标识使用政策。

问题反馈

在 GitHub Issues提交问题时，请说明操作步骤、预期与实际结果。附上源码提交、所用示例或模块、操作系统与编译器版本、完整命令和错误输出。资源问题还应说明资源包来源及核对后的身份。

个人学习计数、用户文稿和设备备份通常不需要公开上传。优先用小型测试资源构造可重现输入；学习问题可以描述状态转换与错误码，避免把个人记录当作必要附件。

参与开发

先运行相关 Host 示例，再提出范围清楚的修改。文档修改应明确调用顺序、缓冲区有效期与失败处理；新平台适配需要说明目标系统、文件接口、调度方式及验证范围。

补充完整独立学习示例前，需要先讨论可公开的选词资格入口及宿主的调用责任。示例应使用与 Alpha 3 一致的记录规则，并覆盖跨方案共享、关闭重开和保存失败处理；当前接入范围见选词学习。
