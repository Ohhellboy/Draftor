# Windows installation

Use desktop Chrome or Edge with Web Serial. Windows Home and Pro editions use the same capability and device checks.

With USB connected, hold PWR to power off, hold BOOT, briefly press PWR to power on, then release BOOT after about two seconds. Before this, save documents, fully power off and remove TF. Select the corresponding USB Serial Device (COM…) or USB JTAG/serial debug unit.

[Installation steps](https://draftor.tcssn.org/guide.html)

[First-time or clean installation](https://draftor.tcssn.org/first-install.html)

Unrecognized firmware can be backed up to a full ZIP, reimported and restored using the saved R13 offline HTML. Confirm the full erase once before installation. Entirely blank devices skip backup only after a complete ROM digest check. After verified contents, fully power off, insert the prepared TF and boot normally.

Generic installation and recovery are software-tested. Windows hardware installation, recovery and boot remain pending.
