# Windows 安装

使用 Windows 11 家庭版或其他具备桌面 Web Serial 能力的 Chrome / Edge。网站按实际浏览器能力、设备芯片、容量和安全状态检查。

现场已成功进入下载模式的顺序为“连接 USB → 长按 PWR 关机 → 按住 BOOT → 短按 PWR 开机 → 等约 2 秒后松开 BOOT”。操作前保存文稿，完全断电后取出 TF。连接窗口选择板对应的 USB 串行设备（COM…）或 USB JTAG/serial debug unit。

[打开完整安装说明](https://draftor.tcssn.org/guide.html)

[第一次安装或清空安装](https://draftor.tcssn.org/first-install.html)

旧固件未识别可继续保存完整 ZIP、回选并保存 R13 离线 HTML，再明确确认一次清空安装。确认全空白的设备跳过备份保存。安装期间保持页面、电源和 USB。出现“内容已校验，普通启动待确认”后再彻底断电、插回准备好的 TF、松开 BOOT 普通开机。

本次通用安装与恢复完成软件验证。Windows 实际安装、恢复及普通启动仍待现场反馈。
