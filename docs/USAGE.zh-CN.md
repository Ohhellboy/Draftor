# 草稿机 Alpha 2.1 操作手册

[English](USAGE.md) | **简体中文**

本手册适用于 ESP32-S3 N16R8（Thick）版本的草稿机，介绍文字输入、文稿改名，以及 USB 和本地 Wi-Fi 文稿传输。尚未安装固件的用户，请先阅读[安装指南](INSTALL.zh-CN.md)。

## 1. 常用按键

| 操作 | 按键 | 说明 |
|---|---|---|
| 切换中英文输入 | `Caps Lock` | 在英文直接输入与中文输入之间切换。 |
| 保存当前文稿 | `Ctrl+S`、`Cmd+S` 或 `F6` | 按下后等待保存完成。 |
| 打开／关闭查找 | `Ctrl+F` 或 `Cmd+F` | 先结束正文组字；在查询框中输入中文或英文。 |
| 打开文件列表 | `F2` | 查看文稿，选择要打开或改名的文件。 |
| 切换横排、竖排 | `F4` | 改变当前的文字排列方向。 |
| 给文稿改名 | `F2` → 选择文稿 → `R` | 在文件列表中选好文稿，再按 `R`。 |
| 打开 USB 传输菜单 | `F9` | 在菜单中按 `E` 导出，按 `I` 导入。 |
| 打开本地 Wi-Fi 页面 | `F10` | 显示连接热点和访问传输网页所需的信息。 |
| 确认菜单选择或操作 | `Enter` | 具体作用见当前页面提示。 |
| 取消或返回 | `Esc` | 具体作用随界面而变，见下文说明。 |

表中的 `F9` → `E` 表示先按 `F9`，再按 `E`，不是同时按住两个键。

同一个按键在写作、候选选择、文件列表和传输菜单中可能有不同作用。操作时请结合当前页面的提示。

## 2. 输入文字与给文稿改名

### 中文输入

草稿机使用 bgIME（大鹅输入法），支持全拼、小鹤双拼和五笔86。按 `Caps Lock` 可以在中文输入和英文直接输入之间切换。

使用中文输入时，输入当前方案的编码，等待候选出现，再按屏幕显示的编号或选词提示选择字词。候选的排列和翻页方式会随输入方案、横竖排布局而变化，请以当前候选区的提示为准。

切换中英文，或进入需要结束当前输入的操作前，先完成选词，或者取消尚未完成的输入。

### 取消正在输入的内容

在正文中输入中文时，`Esc` 是逐步退出：有时会先离开候选选择，返回编码编辑，再继续取消尚未提交的输入。因此，第一次按下后，输入的字母可能还在。

**改名界面的 `Esc` 不同：它会取消整个改名操作，原文件名不变。**

### 保存与横竖排

按 `Ctrl+S`、`Cmd+S` 或 `F6` 保存当前文稿，等待保存完成后再进行后续操作。按 `F4` 可以切换横排和竖排。

### 给文稿改名

草稿机支持中文文件名。改名不会改变文稿正文，也不会自动打开另一篇稿件。

1. 按 `F2` 打开文件列表，选中要改名的文稿。
2. 按 `R` 进入改名界面。
3. 输入或修改文件名。可以使用英文，也可以使用 bgIME 输入中文。
4. 中文输入需要先选好字词。选中的文字进入文件名输入框，此时还没有保存新名字。
5. 确认整个文件名无误后，按 `Enter` 完成改名。

**选好中文和确认改名是两步，不是同一个动作。** 最终确认之前按 `Esc`，会放弃这次改名，包括尚未选完的中文，原文件名保持不变。

在改名框中，字母用于输入文件名，不会触发文件列表中的字母快捷键。改名后需要打开这篇稿件时，请回到文件列表中选择。

### 状态栏与中文查找

横排和竖排的顶部只显示文稿名。底部左侧 `En／双／全／五` 分别表示英文、小鹤双拼、全拼和五笔；右侧显示真实保存状态与蓝牙状态。

保存状态包括“未保存”“等待保存”“保存中…”和“已保存”。遇到保存或存储错误时，设备会显示相应提示；此时应先处理错误，不能把它当作已保存。蓝牙未就绪、配对和可输入时分别显示“未连接”“配对中”和“已连接”；当前版本没有独立的蓝牙关闭开关。需要配对码时，底栏会临时显示六位数字，请在键盘上输入并按回车。

查找时，先完成或取消正文组字，再按 `Ctrl+F` 或 `Cmd+F`。在查询框输入文字，中文选词只写入查询框。完成组字后，`Enter` 查找下一处，`Shift+Enter` 查找上一处，越过文稿边界后回绕；`Ctrl+I` 切换英文大小写匹配。

查询框的光标会沿文字方向移动：横排用左右键，竖排用上下键。按住 Shift 再移动可以选择局部文字；`Ctrl+A` 全选查询，输入文字会替换选区，Backspace 或 Delete 可删除选区。组字期间，方向键和选词键仍按输入法提示操作。

要退出查找，先按 `Esc` 取消未完成组字，再按 `Esc` 返回正文；没有组字时一次即可。也可在查询框中用 `Ctrl+F` 或 `Cmd+F` 关闭查找。查找只定位文字，不提供替换正文的功能。

文件菜单中的长名、回收站和操作提示采用中文；需要查看全部快捷键时，打开菜单内的帮助页。重命名框支持 Shift 局部选择、替换和删除，最终仍以 Enter 确认、Esc 取消。

## 3. 通过 USB 导入、导出文稿

用草稿机的 USB 数据接口连接电脑后，可以像复制U盘文件一样交换 TXT 文稿，不需要联网。

USB 传输分为两种模式：

| 模式 | 电脑上看到的内容 | 用途 |
|---|---|---|
| 导出 | 一个只读磁盘，其中有当前文稿的 `DOCUMENT.TXT` | 把草稿机上的文字复制到电脑。 |
| 导入（Inbox） | 一个临时可写磁盘 | 先接收电脑上的 TXT，再在草稿机上导入为新稿。 |

**无论导入还是导出，结束时都要先在电脑上安全弹出磁盘，再退出草稿机的 USB 界面。**

### 导出到电脑

1. 用 USB 数据线连接草稿机和电脑。
2. 在草稿机上按 `F9`，再按 `E`。
3. 等待电脑显示新的 USB 磁盘，打开它。
4. 将其中的 `DOCUMENT.TXT` 复制到电脑。
5. 在电脑上安全弹出这个磁盘。
6. 回到草稿机，按屏幕提示退出；如果仍停留在 USB 界面，可按 `Esc` 返回。

电脑看到的不是整张 TF 卡，而是当前文稿的一份文本副本。这个磁盘是只读的，不能在里面修改、改名或删除文件。

**导出的文件不会与草稿机实时同步。** 在电脑上修改复制出来的 TXT，不会改变草稿机中的原稿。

### 从电脑导入

1. 用 USB 数据线连接草稿机和电脑。
2. 在草稿机上按 `F9`，再按 `I`。
3. 等待电脑显示 Inbox 磁盘，将需要导入的 `.txt` 文件复制进去。
4. 复制完成后，**在电脑上安全弹出 Inbox 磁盘**。
5. 草稿机会检查收到的文件，并显示可以导入的 TXT。用 `↑`、`↓` 选择文件，按 `Enter` 导入。
6. 导入成功后，按 `Enter` 打开新稿；按 `Esc` 则返回原文稿，不切换到新稿。

**导入会另建一篇草稿，不覆盖你原来的文稿。** 只有明确选择打开新稿时，才会切换正在编辑的文稿。

Inbox 只是临时收件处。文件复制进去后，还需要在草稿机上完成导入；否则退出传输或设备断电后，尚未导入的文件可能丢失。电脑正在写入 Inbox 时，不要拔线或断电。

重要文稿请在电脑上保留原文件，不要把临时收件处当作唯一备份。

## 4. 通过本地 Wi-Fi 传输文稿

草稿机可以开启自己的 Wi-Fi 热点，让手机浏览器访问本地传输页面，导入、导出文稿。不需要场地的 Wi-Fi 网络，也不需要云端账号。

### 连接手机

Wi-Fi 在开机时默认关闭。先完成或取消当前中文输入，等待保存结束；正在使用 USB 传输时，先按上一节的方法退出。

1. 按 `F10` 打开本地热点页面。
2. 在连接二维码页面，用手机扫码连接草稿机的热点。
3. 按 `Tab` 切换到网址二维码页面，再用手机打开本地传输网页。
4. 在手机浏览器中进行文稿导入或导出。

二维码不方便扫描时，可以按 `P` 查看手动连接信息，按照屏幕上的热点和地址连接。

通过 Wi-Fi 导入的文稿也会另存为新稿，不直接覆盖或切换当前正在编辑的文稿。

### 返回写作与关闭热点

按 `Esc` 可以返回写作，**但热点仍然开启**。

结束传输后，需要关闭热点时，按 `F10` 回到 Wi-Fi 页面，再按 `O`。

USB 和 Wi-Fi 文稿传输不能同时使用。需要改用 USB 时，先关闭 Wi-Fi 热点。

## 5. 遇到问题怎么办

如果出现保存错误、异常重启、内存错误，或者屏幕提示 `HALT` 等停止信息，先停止继续输入或重复执行当前操作。

记下屏幕提示，以及出错前做了什么；方便时可以拍照。原因不明时，不要反复强制重启，尤其是在保存或传输过程中。也不要为了排查问题格式化 TF 卡、删除文稿目录或覆盖原有资源。

需要反馈问题时，可以到 [GitHub Issues](https://github.com/Ohhellboy/Draftor/issues) 说明开发板型号、固件版本、操作步骤和实际现象。**不需要上传私人文稿、完整输入日志或 Flash 备份。** 提供截图或诊断信息前，请先检查其中是否含有私人文字或设备信息。

Alpha 2.1 仍是测试版本，重要文稿请定期导出并另存备份。其他限制和隐私说明见[已知问题](KNOWN_ISSUES.md)。
