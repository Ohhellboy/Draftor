# Draftor Alpha 2 / 草稿机 Alpha 2

Alpha 2 makes Chinese input faster and adds local Wi-Fi document transfer. Full Pinyin, Xiaohe Shuangpin, Wubi 86, English and horizontal/vertical writing remain available on ESP32-S3 N16R8 (Thick).

Alpha 2 让中文输入更快，并加入本地 Wi-Fi 文稿传输；继续支持 ESP32-S3 N16R8（Thick）上的全拼、小鹤双拼、五笔86、英文及横竖排写作。

For installation, use the matching Firmware and Resources packages. Alpha 1 users should back up manuscripts and necessary data, erase internal flash, then install Alpha 2 fresh. The TF card does not need formatting. The exact files and commands are in the installation guide.

安装使用同版 Firmware 和 Resources。Alpha 1 用户建议先备份文稿及必要数据，清除内部 Flash 后全新安装 Alpha 2；不需要格式化 TF 卡。准确文件及命令见安装指南。
