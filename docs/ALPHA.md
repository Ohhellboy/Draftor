# Draftor Alpha 2 / 草稿机 Alpha 2

Alpha 2 concentrates on the feel of writing: shorter Chinese candidate waits, earlier letter feedback and faster display after selection. It retains the existing writing and document features on ESP32-S3 N16R8.

Alpha 2 主要改善写作时的跟手感，保留 ESP32-S3 N16R8 上现有输入、编辑及文件功能。此页是尚未发布的本地审阅稿。
