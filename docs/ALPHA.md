# Draftor Alpha 2.1 / 草稿机 Alpha 2.1

Alpha 2.1 adds Chinese Find, Chinese menus and a simpler editor status display. It supports Full Pinyin, Xiaohe Shuangpin, Wubi 86, English and horizontal/vertical writing on ESP32-S3 N16R8 (Thick).

Alpha 2.1 加入中文查找、中文菜单，并整理编辑器状态栏。ESP32-S3 N16R8（Thick）用户可以使用全拼、小鹤双拼、五笔86、英文及横竖排写作。

Use matching Firmware and Resources packages. Alpha 2 users can update only the App after checking the actual layout. Alpha 1 users need the separate fresh-install procedure after backing up their writing and required data. The installation guide explains both routes; neither requires formatting the TF card.

安装使用同版 Firmware 和 Resources。Alpha 2 用户确认实际布局兼容后可只更新 App；Alpha 1 用户则需先备份，再走全新安装流程。安装指南分别说明了两种路径，都不要求格式化 TF 卡。
