# 草稿机 Alpha 3 · 微雪：选词学习、七候选与键盘回连

**简体中文** | [English](RELEASE_NOTES.md)

Alpha 3 微雪版 **ESP32-S3-RLCD-4.2（ST7305）** 加入选词学习：常选的词逐渐往前排；优化了候选词显示逻辑与数量，每行或每列最多显示7个候选词；重做了蓝牙键盘的连接与回连逻辑，连接速度更快。

本次首先发布微雪版固件和配套学习索引。下载及安装方式见文末。

## 让常选的词往前排

大鹅输入法加入了选词学习。原本排在后面的词，被多次选中后，可以排得更靠前。全拼、小鹤双拼和五笔86共用这份学习记录，换一种输入方式，同一个词仍能用上之前积累的学习记录。

正常开机后，学习自动开启，屏幕会提示 `Learning ON`。学习记录保存在 TF 卡中，保存并重新开机后可以继续使用。

想清除某个词的学习记录，可以在7个候选词显示时，按 `Ctrl+1` 至 `Ctrl+7`，清除当前行或列中已显示的对应编号词条的记录。

## 横竖排最多7个候选

输入中文时，横排每行、竖排每列最多显示7个带编号的候选，按对应数字即可选中。多字候选词按实际字数排布，优先留出完整词语所需的位置，每行或每列的项数也随之变化（双字候选词每行4个候选项，三字候选词每行2个候选项）。查找框的候选仍为每行最多6项。

末尾有时会露出下一个词的首字，提示后面还有候选。翻到下一行或下一列后，才能按编号正常选择该提示词。展开候选区后，如果下一行或下一列已经显示出来，这个首字提示就会收起。

## 键盘配对与日常回连

草稿机最多保存3份键盘配对记录。第一次连接新键盘时，长按键盘信道键进入配对模式，并按草稿机屏幕下方的提示完成配对；如需配对码或本机确认，按提示操作。若配对码输入错误，重启键盘后重新进入配对模式连接即可。

已经配对过的键盘，短按原信道键即可重新连接，不需要每次都长按重新配对。

草稿机每次只连接一把蓝牙键盘。换用另一把已经配对的键盘时，先关闭或断开正在使用的键盘，再打开并短按下一把的原信道键。当前键盘保持连接时，草稿机不会主动切到另一把键盘。

保存满三份记录以后，如果要加入第四把键盘，长按新键盘的信道键完成配对；只有配对和必要确认成功，才会替换最早保存的那一份。平时短按连接或打字，不会改变这个顺序。

## 保存文稿，也保存选词习惯

写作时，按 `F6` 或 `Ctrl/cmd+S` 保存当前文稿，等保存完成后继续输入。

准备关机时，先完成当前输入并回到正文，再按 `Ctrl+F6`。草稿机会一并保存文稿和学习记录；等屏幕显示 `Saved; safe power off`（已保存，可以关闭电源），再断电。如果还想接着写，再按一次 `Ctrl+F6`，即可恢复学习。

注意，`F6` 或 `Ctrl/cmd+S` 是保存文稿，`Ctrl+F6` 是【保存文稿+保存近期学习记录+关闭/开启学习】三项功能的复合功能键。逻辑有点乱，未来会调整。

## 屏幕和原有功能

微雪版的默认显示方向旋转了 180°，正文、候选和菜单一起转向。本固件将板载 TF 卡接口配置为 1-bit SDMMC、40 MHz。

横竖排写作，中文与英文查找，本地文稿管理，以及 USB 导入、导出功能保留。本地 Wi-Fi 文稿传输仍属于实验功能。重要文稿请定期导出，另存一份备份（尤其是更新固件前！）。

## 下载与升级

本批发布 **微雪 ESP32-S3-RLCD-4.2（ST7305）** 专用的 Alpha 3 固件。请到 [GitHub Releases](https://github.com/Ohhellboy/Draftor/releases) 下载微雪版固件及配套资源，并按照[中文安装指南](INSTALL.zh-CN.md)操作。

新版可以沿用兼容的词库和字体，但需要额外的学习索引。已有 TF 卡不用为了升级而格式化；请按本版指南加入学习索引，核对文稿和学习目录。**只更换固件不会自动迁移旧文稿。**升级前务必备份文稿和已有学习记录。

Alpha 3 将按 **微雪 → 原版 ESP32-S3 N16R8＋Osptek ST7306 → Raspberry Pi Pico 2 W** 的顺序分批发布，三批都使用 Alpha 3 名称，各自使用对应固件，不能混刷。本批仅提供微雪版；其他硬件的 Alpha 3 固件随后发布。历史版本仍可从 [GitHub Releases](https://github.com/Ohhellboy/Draftor/releases) 获取。
