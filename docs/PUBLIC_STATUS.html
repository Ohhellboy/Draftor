清空安装

用户核实微雪 ESP32-S3-RLCD-4.2 / ST7305 后，核对 ESP32-S3、16 MiB 容量、安全状态和目标发行文件。不同厂家版本、未知旧固件、未知分区、残留数据和全空白均可清空安装。非空设备先保存、回选实际原机完整 ZIP 并保存 R13 离线工具，最后明确确认一次覆盖全部内部 Flash。全空白必须经完整 ROM 摘要核实才可跳过备份。

保留数据重装

仍限准确 Alpha 3 app0 同版本，保留分区、安全和保护区域检查。无法确认兼容时提供“备份后清空安装”入口。

完整备份和恢复

未知原固件按实际全部 16 MiB 内容保存。通用包使用 draftor-private-recovery/2，原有 /1 包继续可读。恢复核对包完整性、原设备身份和安全条件，不要求当前 Flash 能启动或分区完好。擦除与写回后均核对实际内容。小型保护 JSON 与完整 ZIP 用途不同，离线完整恢复仍使用 ZIP。

验证状态

本次新准入、备份导入、清空安装、擦写校验和通用恢复完成软件模拟回归。Windows 11 家庭版 Chrome 现场已确认 BOOT＋PWR 能出现串口和连接。新版本的 Windows 真实安装、恢复和普通启动仍待现场反馈，windowsDevice 为 PENDING。此前 R12 macOS 同版本实机重装结果作为已有证据保留。
