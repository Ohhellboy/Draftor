# 原设备完整恢复

1. 先关闭其他安装页和串口程序。保存手头工作，彻底断电后取出 TF。
2. 保持 USB 接好，长按 PWR 关机。按住 BOOT，短按 PWR 开机，约两秒后松开 BOOT。
3. 在 Chrome 或 Edge 按 Ctrl+O（Mac 按 ⌘O），打开已经保存的 Draftor_Recovery_R13_Offline.html。
4. 选择“恢复原设备”，导入同一块板保存的完整私人 ZIP。支持原有 v1 包和本次未知固件的 v2 包。
5. 核对板型和取卡条件，选择 USB 串口并连接。即使当前固件或分区损坏，也会根据 ROM 和包核验原设备。
6. 阅读整片覆盖说明，确认一次恢复。保持电源、USB 和页面，等待擦除、写回及内容校验。
7. 内容已校验后，点“关闭连接并清除私人会话”，彻底断电，插回原 TF，普通启动。

恢复会回到包里的原程序与数据。原程序可能是其他固件、厂家演示或空白。内容校验成功只说明与备份一致，启动结果取决于备份时的系统。TF 独立保存。

若页面说明“尚未擦除或写入”，可以纠正文件或连接后重新开始。擦写已经开始后出错时保留现场和脱敏回执，停止连续重试。未知固件的新包应使用 R13 离线工具；更早工具只认识其原有备份类型。私人 ZIP 和保护 JSON 不要上传。
