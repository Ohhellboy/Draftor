# Hardware / 硬件

## MCU / 单片机
- ESP32-S3 N16R8
- Raspberry Pi Pico 2 W

## Display / 屏幕
- Osptek ST7306 black-white-red reflective TFT

## Input / 输入
- Bluetooth keyboard
- Standard English-layout keyboards for macOS and Windows

## Storage / 存储
- microSD / TF card

## Current prototype / 当前原型
The current prototype shown in the README uses an ESP32-S3 N16R8, an Osptek ST7306 display, a Bluetooth keyboard, and TF-card storage.

README 中展示的当前原型使用 ESP32-S3 N16R8、鱼鹰 ST7306 反射屏、蓝牙键盘和 TF 卡存储。
