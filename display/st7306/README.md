# ST7306 Display Support / ST7306 屏幕支持

Draftor currently supports the Osptek ST7306 black-white-red reflective TFT display.

草稿机目前支持鱼鹰 Osptek ST7306 黑白红三色反射式 TFT 屏幕。

## Current status / 当前状态

- Text display working
- Black / white / red output supported
- Driver adjusted from the official implementation for text-oriented use
- Currently used in the Draftor prototype

- 文本显示已可用
- 支持黑 / 白 / 红三色
- 驱动基于官方实现进行文本显示方向的调校
- 当前已用于 Draftor 原型机

## Planned / 后续

A minimal standalone demo and source code will be added progressively.

后续将逐步加入最小独立示例和相关源码。
