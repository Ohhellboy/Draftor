# ST7306 Display Support / ST7306 屏幕支持

Draftor currently supports the Osptek ST7306 black-white-red reflective TFT display.<br>
草稿机目前支持鱼鹰 Osptek ST7306 黑白红三色反射式 TFT 屏幕。

## Current Status / 当前状态

- Text display working / 文本显示已可用
- Black / white / red output supported / 支持黑 / 白 / 红三色
- Driver tuned from the official implementation for text-oriented display use / 驱动基于官方实现进行文本显示方向的调校
- Currently used in the Draftor prototype / 当前已用于 Draftor 原型机

## Planned / 后续

A minimal standalone demo and related source code will be added progressively.<br>
后续将逐步加入最小独立示例和相关源码。
